# 配管計算

電気の配管工事で使う、電線管どうしの距離（ピッチ）と管の寸法を出すツールです。
ビルド不要の静的サイトなので、`index.html` をブラウザで開くだけで動きます。
現場のスマホでもオフラインで使えます。

## 使い方

```
git clone https://github.com/satoshimr929-cyber/haikan.git
cd haikan
```

そのまま `index.html` を開くか、ローカルサーバーで開いてください。

```
npx serve .
```

GitHub Pages に置く場合は、リポジトリ設定の Pages でブランチのルートを指定するだけです。

## できること

### ピッチ・割り付け

| モード | 内容 |
| --- | --- |
| 2本の芯々 | 2本の管の外径とあきから芯々距離を出す。逆に芯々距離からあきを逆算し、干渉していれば警告する |
| 均等割り付け | 有効幅に同じ径の管を並べる。最大本数・本数指定での均等割り・ピッチ指定での必要幅の3通り。左端からの芯の累計を墨出し表で出す |
| サイズ混在 | 径の違う管を左から順に並べ、各管の芯位置・隣とのピッチ・あきを出す。あきを決めて総幅を出す／総幅を決めてあきを逆算する／隣り合う管ごとに芯々ピッチかあきを個別指定する、の3通り |
| 曲げのずらし | 並行配管を同じ角度で曲げるとき、隣の管の曲げ位置をどれだけずらすか。曲げた先のピッチを手前と変えることもできる |
| サドル・支持点 | 配管の全長から、サドルの数と位置を出す。管の接続点（カップリング）を入れると、サドルが当たらないかを確認できる |

**サイズ混在の個別指定**では、ペアごとに「芯々ピッチ」と「あき」のどちらで入れるかを選べます。
図面で芯々が決まっている箇所と、あきだけ決まっている箇所を混ぜて入力できます。指定していない
ほうの寸法は入力欄の横に出ます（種類を切り替えると、配置が変わらないように値を換算します）。

**曲げのずらし**では、曲げ角度はどの管も同じまま曲げ位置のずらし方だけでピッチを変えられます
（ラックから盤へ入るときなど）。曲げた先のピッチを空欄にすると手前と同じ扱いです。
ピッチを狭める場合はずらし量が負になり、外側の管のほうが手前で曲がります。

サイズ混在で並べた配管は、そちらの「**曲げのずらしへ送る**」でそのまま持ち込めます。
径が違えばピッチも変わるので、**ペアごとに別のずらし量**を計算します。曲げた先のピッチに
値を入れれば、ばらばらの並びを盤の側で一定ピッチに揃えることもできます。

**サドル・支持点**の上限間隔は、金属管 2m 以下・合成樹脂管 1.5m 以下を目安として入れています
（金属製可とう電線管は 1m 以下。ボックスや管端からは 0.3m 以内）。
現場や施工要領の基準があれば、入力欄を書き換えてください。

管の接続点は**定尺から自動で並べ、個別にも足せます**。継ぎ方は2通りから選べます。

| 継ぎ方 | 6m を定尺 3.66m で継ぐ場合 |
| --- | --- |
| 定尺＋半端（端から） | 3660 + 2340。端材は 1320mm が1つ |
| 均等（センターで継ぐ） | 3000 + 3000。継ぎが真ん中に来る。端材は 660mm が2つ |

定尺＋半端では「最初の継ぎまで」も指定できます（現場では1本目を切って合わせるため）。
PF管・CD管はコイル巻きで定尺がないため、個別入力だけになります。

あわせて**管の拾い**も出します。必要な定尺の本数、どの定尺からどの長さを切るか、
端材がどれだけ出るかが分かります。切り出しは長いものから順に詰めていくので
（first-fit decreasing）、短い管が複数あれば1本の定尺からまとめて取ります。

接続点との関係は**材質によって規定そのものが違う**ので、動きも変えています
（出典：公共建築工事標準仕様書 電気設備工事編）。

| 種別 | 支持間隔 | 管相互の接続点 | このアプリの動き |
| --- | --- | --- | --- |
| 金属管 | 2m 以下 | 明記なし（ボックス等との接続点・管端が対象） | 当たらないか確認し、当たれば逃がし先を出す |
| 合成樹脂管 | 1.5m 以下 | 支持対象（PF/CD管は接続点の両側） | 接続点の両側に支持を置いてから、間を上限以下で埋める |

両側に置くかどうかは「材質にしたがう／置く／置かない」から選べます。規定は「両側」としか
言わないので、接続点から支持までの距離は入力にしています（カップリングに当たる値を入れた場合は、
当たらない位置まで自動で広げます）。

なお内線規程にも同様の規定があるとされますが、原文は未確認です（第三者解説による確認にとどまる）。
そのため出典は一次資料である公共建築工事標準仕様書としています。

### 曲げ加工

| モード | 内容 |
| --- | --- |
| オフセット（振り） | 段差を2箇所の曲げで越えるときの、曲げと曲げの間隔（墨の間隔）・縮み代・倍率 |
| 曲げの取り代 | 曲げ半径から取り代と切断長、曲げ始めの墨位置。管を選ぶと最小曲げ半径と突き合わせる |
| 障害物よけ | 梁やダクトをまたぐときの墨位置。3方曲げ（中央が側面の2倍の角度）と4方曲げ |

オフセットと障害物よけは**曲げ半径のない折れ線として計算**しています。実際のベンダーでは
半径のぶん差が出るので、1本目は現物合わせで確かめてください。曲げの取り代だけは半径を扱います。

取り代モードで管を選ぶと、内線規程の「曲げの内側の半径は管内径の6倍以上」と突き合わせて、
下回っていれば警告します。

結果は数値だけでなく図（SVG）でも表示します。管の選択は寸法表から選ぶほか、
外径を直接入力することもできます（実測値やカタログ値を使いたいとき）。

### 入力の保存

入力した値と、開いていたタブ・モードはブラウザに保存されます。閉じて開き直しても続きから
使えます。ヘッダーの「入力をリセット」で、すべて既定値に戻せます（確認あり）。

保存先は localStorage です。プライベートブラウズなどで使えない環境では、保存なしでそのまま
動きます（エラーにはなりません）。同じブラウザの中だけなので、端末をまたいでは引き継がれません。

### 寸法表

E管・C管・G管・PF管・CD管・VE管・ポリエチライニング電線管の呼び径ごとの
外径・内径・肉厚。種類の絞り込みと検索付き。

## 計算式

- 芯々距離 = (外径1 + 外径2) ÷ 2 + 管と管のあき
- 有効幅 W に外径 d を端あき m・最小あき g で並べたときの最大本数
  = ⌊(W − 2m − d) ÷ (d + g)⌋ + 1
- n 本の均等割りピッチ = (W − 2m − d) ÷ (n − 1)
- 総幅 W に n 本（外径の合計 ΣD）を等間隔で収めるときのあき
  = (W − 2m − ΣD) ÷ (n − 1)
- ピッチを個別指定したときの i 番目の芯 = (i−1 番目の芯) + ピッチ、
  そのペアのあき = ピッチ − (外径ᵢ₋₁ + 外径ᵢ) ÷ 2
  （あきで指定した場合は ピッチ = あき + (外径ᵢ₋₁ + 外径ᵢ) ÷ 2 に直してから同じ計算）
- 支持点の本数 = max(2, ⌈(全長 − 端からの距離×2) ÷ 上限間隔⌉ + 1)、
  実間隔 = (全長 − 端からの距離×2) ÷ (本数 − 1)
- 接続点の位置
  - 定尺＋半端: 最初の継ぎまでの距離 + 定尺 × n（＋個別に指定した分）
  - 均等: 必要な本数 ⌈全長 ÷ 定尺⌉ で等分した位置
- 管の拾い: 接続点で区切った長さを、長いものから定尺に詰める（first-fit decreasing）
- サドルと接続点が当たる条件 = |サドルの芯 − 接続点| < (カップリング長 + サドル幅) ÷ 2
  - 各サドルから最寄りの接続点までの距離を墨出し表に出し、図にも寸法として入れます。
    当たる境目（上の右辺）も画面に出すので、当たっていなくても余裕がどれだけあるか分かります
  - 逃がし先は接続点の手前と先の両方を試し、両隣との間隔が上限以下に収まり、
    ほかの接続点とも当たらないほうを選びます（移動量の小さいほうを優先）
- 並行配管の曲げ位置ずらし量
  = (曲げた先のピッチ − 手前のピッチ × cos角度) ÷ sin角度
  - 手前と同じピッチにする場合は 芯々ピッチ × tan(角度 ÷ 2) に一致します
  - 90° では ずらし量 = 曲げた先のピッチ（手前のピッチは効きません）
  - ピッチが管ごとに違う場合は、隣り合うペアごとに同じ式で出して足し合わせます

曲げ加工（θ = 曲げ角度、h = 段差または障害物の高さ、R = 曲げ半径）:

- オフセットの斜辺 = h ÷ sinθ、水平投影 = h ÷ tanθ、縮み代 = h × tan(θ ÷ 2)
- 曲げの接点まで（交点から）= R × tan(θ ÷ 2)、円弧長 = R × θ、
  取り代 = 接点まで × 2 − 円弧長、切断長 = 外寸A + 外寸B − 取り代
  - 90° では 取り代 = R × (2 − π ÷ 2) ≒ 0.4292R
- 3方曲げの中央から両側の墨まで = h ÷ sinθ（中央の角度は 2θ）
- 4方曲げの立ち上がり = h ÷ sinθ、上を通る直線部 = 障害物の幅 + 逃げ × 2
- 障害物よけの縮み代（3方・4方とも）= h × tan(θ ÷ 2) × 2
- 最小曲げ半径（内線規程）: 内側の半径 = 管内径 × 6、管の芯では + 外径 ÷ 2

## テスト

計算ロジックは `assets/calc.js` に純関数として切り出してあり、依存なしで実行できます。

```
npm test        # または node test/calc.test.js
```

図（SVG）の検査は別立てで、Playwright が入っている環境でのみ動きます。
ラベルが枠から切れていないか・重なっていないか・横スクロールが出ていないか・
JS エラーが出ていないかを、画面幅と入力値を振って調べます。

```
node test/figures.js
# Playwright の場所を指定する場合
PLAYWRIGHT_MODULE=/path/to/playwright node test/figures.js
```

## 構成

```
index.html          画面
assets/data.js      電線管の寸法データ
assets/calc.js      計算ロジック（純関数・Node からも require 可）
assets/figures.js   図（SVG）の組み立て。DOM に触らず文字列を返すだけ
assets/app.js       UI の配線
assets/style.css    スタイル（ダーク／ライト自動切り替え）
test/calc.test.js   計算ロジックのテスト
test/figures.js     図の検査（Playwright・任意実行）
```

寸法を追加・修正したいときは `assets/data.js` の `PIPE_SERIES` に手を入れれば、
セレクトボックスも寸法表も自動で追従します。

## 出典と注意

- 鋼製電線管（ねじなし・薄鋼・厚鋼）: JIS C 8305
- 硬質ビニル電線管: JIS C 8430
- 合成樹脂製可とう電線管（PF管・CD管）: JIS C 8411
- ポリエチライニング電線管（PE管）: JIS C 8380 G形。鋼管部は JIS C 8305 の厚鋼電線管と同寸

PF管・CD管の外径はメーカーや単層・複層の別で数 mm 変わるため、アプリ内でも代表値と
明示しています。

PE管は呼びが厚鋼電線管と同じ G16〜G104 で、鋼管部の外径・肉厚も厚鋼電線管の規格値
そのまま。そこに内外面のポリエチレン被覆が乗ります。**仕上外径・鋼管の外径・品番は
パナソニックのカタログ値**で、外面被覆はどのサイズも片側 0.6mm です。

内径だけは内面被覆も 0.6mm として計算した代表値（`id = steelOd − t×2 − coating×2`）
なので、通線本数を詰める場合はカタログで確認してください。

呼びが G管と重複するため、内部ではシリーズ込みのキー（`PE:G28` / `G:G28`）で
サイズを識別しています。`findSize()` はキーでも呼びだけでも引けます（呼びだけの場合は
先に定義されたシリーズを返します）。画面上は重複する呼びにシリーズ名を付けて
「PE管 G28」「G管 G28」と表示します。

狭い場所の納まりや、カップリング部で干渉しそうな箇所は、
必ずメーカーカタログと施工要領で確認してください。
このツールの計算結果は施工図・施工要領の代わりにはなりません。
