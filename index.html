電線管 寸法表

鋼製電線管は JIS C 8305、硬質ビニル電線管は JIS C 8430 の規格値。PF管・CD管の外径と、 ポリエチライニング電線管（JIS C 8380）の外径・内径は被覆厚から求めた代表値で、 メーカーにより差があります。実施工では必ずメーカーカタログと施工要領で確認してください。
